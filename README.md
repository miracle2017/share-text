## 🤔 它解决什么问题？

你有没有遇到过这些场景：

- 📱 手机上复制了一段文字，想发到电脑上，但不想开微信/QQ
- 💻 电脑上有个链接/密码想快速传到手机，又懒得扫文件二维码
- 🔒 内容比较私密，不想经过第三方服务器，但又要传到另一台设备

**TextSync 就是为这些场景设计的。**

---

## ✨ 三种传输方式，总有一款适合你

### 💻 → 📱 &nbsp; 电脑传手机：扫码直传

在电脑网页上输入文字，右侧**实时生成二维码**。

用手机相机、微信扫一扫——文字瞬间出现在手机屏幕上。

```
输入文字 → 实时二维码 → 手机扫码 → 获取文本
```

---

### 📱 → 💻 &nbsp; 手机传电脑：4位提取码

手机上点击"生成提取码"，得到一个 **4 位数字**，有效期 3 分钟。

在电脑上输入这个 4 位数字，文字立刻出现。

```
手机输入 → 生成【1234】→ 电脑输入1234 → 获取文本
```

> 专门解决"电脑没摄像头扫不了码"的痛点。

---

### 🔗 → 🔗 &nbsp; 链接直传：免提取码

文字被**编码压缩进网址链接**里，扫码或直接发链接给对方，对方打开即自动解码。

```
输入文字 → 生成分享链接 → 发给对方 → 打开即解码
```

> 适合局域网环境、没有输入提取码条件，或想把内容永久保存成链接。
